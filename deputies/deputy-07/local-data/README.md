# مرکز داده و پشتیبان‌گیری شرکت هفت

این پوشه برنامه مستقل آفلاین و نسخه وب نصب‌پذیر مرکز داده معاونت ۷ را نگهداری می‌کند.

## معماری نسخه اولیه
- رابط وب مستقل و قابل نصب (PWA)، بدون CDN یا سرویس خارجی؛ امکان ثبت رکوردهای JSON و فایل‌های پیوست تا سقف ۲۰ مگابایت برای هر فایل.
- بسته‌بندی دسکتاپ ویندوز با Tauri 2.
- مخزن محلی IndexedDB در نسخه وب و WebView دسکتاپ؛ نسخه دسکتاپ یک snapshot رمزگذاری‌شده را در پوشه AppData نگهداری می‌کند.
- رمزگذاری AES-256-GCM و مشتق‌سازی کلید با PBKDF2-SHA256 و ۳۱۰٬۰۰۰ دور.
- بسته تبادل H7BACKUP رمزگذاری‌شده، شامل رکوردها و پیوست‌ها، قابل انتقال با USB یا پوشه اشتراکی شبکه داخلی.
- دفتر تغییرات، شناسه مستقل رایانه، حذف منطقی و شناسایی شاخه‌های متعارض.

## اجرا در مرورگر
از مسیر انتشار GitHub Pages، پوشه local-data را باز کنید. برای نصب PWA، سایت باید در HTTPS باز شود. سرویس‌ورکر پس از اولین بارگذاری، فایل‌های رابط را برای اجرای آفلاین کش می‌کند.

## ساخت نرم‌افزار ویندوز
نیازمند Node.js، Rust و پیش‌نیازهای ساخت Tauri 2 در ویندوز است:
- npm install
- npm run tauri -- build

خروجی بسته نصب در مسیرهای استاندارد Tauri زیر src-tauri/target/release/bundle تولید می‌شود.

## مسیر داده در نرم‌افزار دسکتاپ
پس از بازگشایی مخزن، مسیر AppData در صفحه نمایش داده می‌شود. فایل جاری با نام vault-state.h7vault، نسخه جایگزین بازیابی و snapshotهای روزانه در همان پوشه و زیرپوشه snapshots نگهداری می‌شوند. بسته‌های دستی در زیرپوشه backups ذخیره می‌شوند؛ برای انتقال با USB، فایل‌های h7backup را از این پوشه کپی کنید.

## انتقال داده از نسخه وب به نرم‌افزار دسکتاپ
۱. نسخه وب را در همان مبدأ GitHub Pages باز کنید و مخزن مرورگر را بازگشایی کنید.
۲. ابزار «انتقال اطلاعات مرورگر» را اجرا کنید تا کلیدهای شناخته‌شده معاونت ۷ وارد مخزن شوند.
۳. یک بسته پشتیبان رمزگذاری‌شده بسازید و فایل h7backup را دریافت کنید.
۴. فایل را به رایانه مقصد منتقل کنید؛ در نرم‌افزار دسکتاپ یک مخزن بسازید/بازگشایی کنید و بسته را وارد کنید.
۵. گذرواژه بسته با گذرواژه مخزن محلی متفاوت است و هنگام واردکردن، گذرواژه بسته درخواست می‌شود.

## نکات امنیتی و عملیاتی
- گذرواژه اصلی را در محل امن و جدا از رایانه‌ها نگهداری کنید؛ بدون آن بازیابی بسته رمزگذاری‌شده ممکن نیست.
- بسته‌های پشتیبان را حداقل در دو رسانه مستقل نگهداری و بازیابی را دوره‌ای آزمایش کنید.
- این نسخه هسته مخزن و تبادل را فراهم می‌کند؛ اتصال همه فرم‌های قدیمی وب به این هسته نیازمند مهاجرت تدریجی ماژول‌های فعلی از localStorage است. تا پایان آن مهاجرت، داده‌های قدیمی را از ابزار انتقال اطلاعات مرورگر وارد کنید.
- در نسخه وب، رمزگذاری مربوط به داده‌هایی است که به این مخزن وارد می‌شوند؛ GitHub Pages به‌تنهایی احراز هویت واقعی یا حفاظت سمت سرور برای محتوای عمومی فراهم نمی‌کند.
- نسخه فعلی یک گذرواژه اصلی برای بازگشایی مخزن دارد؛ نقش‌های مستقل رئیس، مدیر اداره و کارشناس و محدودیت دسترسی رکوردی هنوز پیاده‌سازی نشده‌اند. تا تکمیل آن، فقط در حساب کاربری و رایانه مورد اعتماد استفاده شود.
- فایل نصب امضاشده و آزمون‌شده ویندوز پس از ساخت روی محیط ویندوز تولید خواهد شد.
