راهنمای اجرای محلی سامانه مأموریت‌های معاونت ۷
=================================================

راهکار استاندارد
----------------
سامانه با Python 3 و وب‌سرور استاندارد داخلی Python روی نشانی localhost اجرا می‌شود.
نیازی به نصب دیتابیس، MySQL، MariaDB، XAMPP یا اتصال به هاست نیست.

نصب یک‌باره
-----------
1) از وب‌سایت رسمی Python نسخه Windows را دریافت کن:
   https://www.python.org/downloads/windows/
2) هنگام نصب حتماً گزینه Add Python to PATH را فعال کن.
3) پس از پایان نصب، فایل START-OFFLINE.bat را دوبار کلیک کن.

اجرای روزانه
------------
1) فایل START-OFFLINE.bat را اجرا کن.
2) سامانه در مرورگر با نشانی زیر باز می‌شود:
   http://127.0.0.1:8766/deputies/deputy-07/pages/mission-create.html
3) پنجره سرور محلی را تا پایان استفاده باز نگه دار.
4) برای توقف سرور، پنجره «سرور محلی معاونت ۷» را ببند.

ذخیره اطلاعات
-------------
اطلاعات مأموریت‌ها در IndexedDB مرورگر ذخیره می‌شود.
برای دسترسی به همان داده‌ها همیشه از همان رایانه، همان مرورگر و همان نشانی localhost استفاده کن.
پاک‌کردن داده‌های مرورگر یا تغییر مرورگر/پروفایل می‌تواند اطلاعات محلی را حذف یا غیرقابل‌دسترسی کند.
برای انتقال داده‌ها از صفحه «مدیریت داده‌های محلی» فایل JSON دریافت و در رایانه مقصد بازیابی کن.

نکته
----
Python فقط فایل‌های سایت را از طریق localhost به مرورگر ارائه می‌کند؛
Python دیتابیس نیست و اطلاعات مأموریت‌ها را روی سرور یا هاست ذخیره نمی‌کند.
