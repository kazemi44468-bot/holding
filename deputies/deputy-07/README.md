# معاونت شماره ۷ — شرکت هفت

این پوشه برای انتقال و توسعه محتوای مخزن `khadamatshahr` در ساختار هلدینگ در نظر گرفته شده است.

فایل‌ها و پوشه‌های پروژه را در همین مسیر بارگذاری کنید. پس از بارگذاری، ساختار و مسیرهای داخلی بررسی می‌شوند تا صفحات و منابع بدون تغییر در سایر بخش‌های هلدینگ یکپارچه شوند.
