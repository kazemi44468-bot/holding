۱. مخزن محلی و آفلاین

داده‌های عملیاتی از طریق موتور ذخیره‌سازی مشترک در مرورگر نگهداری می‌شوند؛ در نسخه دسکتاپ معاونت ۷، snapshot رمزگذاری‌شده نیز در پوشه داده برنامه ذخیره می‌شود.

محلی
مخزن عمومی هلدینگIndexedDB مرورگر · فضای داده مستقل برای هر مرکزدر حال خواندن آمار…
مرکز دسکتاپ معاونت ۷اجرای محلی با سرویس loopback یا برنامه دسکتاپ Tauriفایل اجرای مرکز محلی (ویندوز)

نکته: داده‌های مرورگر به همان مرورگر و دستگاه وابسته‌اند. برای انتقال به دستگاه دیگر، از پشتیبان‌گیری خود مرکز استفاده کنید. GitHub Pages امکان نوشتن مستقیم در پوشه پروژه یا فایل SQLite روی رایانه را نمی‌دهد.

۲. تعریف اتصال دیتابیس هاستینگ

اطلاعات سرور را به‌صورت پروفایل ذخیره کنید. رمز عبور فقط برای آزمایش اتصال در همان نشست استفاده می‌شود و در مرورگر، مخزن محلی یا GitHub ذخیره نخواهد شد.

سروری
برای اتصال واقعی، سرویس واسط سمت سرور باید پیاده‌سازی و روی هاست نصب شده باشد.

۳. اتصال‌های تعریف‌شده

رمز عبور در فهرست پروفایل‌ها وجود ندارد. برای تغییر رمز دیتابیس، رمز جدید را فقط هنگام آزمایش اتصال وارد کنید.

هنوز پروفایل اتصالی ثبت نشده است.

۴. وضعیت اتصال و سیاست همگام‌سازی

اتصال آنلاین، مرجع داده و انتقال تغییرات باید از طریق API امن و کنترل‌شده مدیریت شود.

مرجع دادهمحلی یا سروری باید برای هر مرکز مشخص شود؛ تغییر مرجع بدون برنامه مهاجرت انجام نمی‌شود.
تعارض‌هاویرایش‌های هم‌زمان باید با شناسه نسخه و زمان تغییر بررسی شوند؛ هیچ داده‌ای خودکار بازنویسی نمی‌شود.
تعویض رمزپس از تغییر رمز در پنل هاست، پروفایل را انتخاب و رمز جدید را وارد و اتصال را آزمایش کنید.
امنیت سروراعتبارنامه دیتابیس فقط در سرور نگهداری می‌شود؛ مرورگر صرفاً با API احراز هویت‌شده ارتباط می‌گیرد.
وضعیت فعلی: این صفحه مدیریت پروفایل و نگهداری محلی را فراهم می‌کند. اتصال واقعی MySQL/PostgreSQL تا زمان نصب API سمت سرور فعال نمی‌شود؛ وارد کردن مشخصات در این صفحه به‌تنهایی به معنی اتصال به دیتابیس نیست.
