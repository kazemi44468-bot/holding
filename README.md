# هلدینگ | درگاه اجرایی و سامانه‌های تخصصی

این مخزن، محل پیاده‌سازی اجرایی درگاه هلدینگ و مراکز/سامانه‌های تخصصی آن است. مخزن [tarhha](https://github.com/kazemi44468-bot/tarhha) مرجع طرح مادر، معماری سازمانی، اسناد مفهومی و نیازمندی‌های تفصیلی باقی می‌ماند.

## وضعیت فعلی

- درگاه اصلی هلدینگ: طبقه‌بندی پنج‌گانه معاونت‌های هلدینگ، شرکت‌های تابعه، مدیریت شعب استانی، مراکز مشترک و سامانه‌ها؛ سامانه‌ها در شش حوزه تخصصی زیرگروه‌بندی شده‌اند.
- مرکز مدیریت دانش: سامانه ثبت، نگهداری و بازیابی دانش و تجربه، شبکه خبرگان، تألیف و انتشارات، بررسی محتوا، گزارش‌ها و تبادل آفلاین.
- زیرساخت ذخیره‌سازی محلی و پشتیبان‌گیری: خدمت مشترک مبتنی بر IndexedDB که هر مرکز در فضای داده مستقل خود از آن استفاده می‌کند؛ صفحه مستقل یا مرکز عملیاتی جداگانه‌ای برای آن ایجاد نشده است.
- مرکز پروژه‌ها و مدیریت یکپارچه کارها: نسخه محلی توسعه‌یافته برای سبد پروژه، WBS چندسطحی، نقاط عطف، وابستگی، گانت، تقویم کاری، ظرفیت منابع، RAID، تغییر و تحویل‌دادنی‌ها.

## اصول اجرایی

1. **مخزن اجرایی:** تمام صفحات و کدهای قابل استفاده در این مخزن ساخته می‌شوند.
2. **مرجع معماری:** اسناد مادر و تصمیم‌های کلان در مخزن `tarhha` نگهداری می‌شوند.
3. **یکپارچگی سازمانی:** شناسه‌های پایدار سازمانی از رجیستری مرکزی خوانده می‌شوند؛ نام‌های تصویب‌نشده حدس زده نمی‌شوند.
4. **ذخیره‌سازی محلی:** تا زمان استقرار زیرساخت مرکزی، هر مرکز داده‌های خود را با فضای نام مستقل در هسته محلی نگهداری می‌کند.
5. **پشتیبان‌گیری و بازیابی:** خروجی قابل انتقال، ورود کنترل‌شده و حفظ تاریخچه برای داده‌های هر مرکز پیش‌بینی می‌شود.
6. **شفافیت وضعیت:** داده نمونه یا عدد ساختگی نباید به‌عنوان عملکرد واقعی نمایش داده شود؛ وضعیت خالی با صفر و پیام روشن نمایش داده می‌شود.
7. **امنیت و ممیزی:** قلمرو سازمانی، نقش، محرمانگی، ثبت عامل و زمان تغییر و نگهداری سوابق باید در طراحی لحاظ شوند.
8. **رابط کاربری:** فارسی و راست‌چین، واکنش‌گرا، خوانا، با هدر و فوتر هماهنگ، فونت‌های محلی و پالت رسمی آبی/طلایی؛ از سبز غالب استفاده نمی‌شود.

## نکته درباره استقرار

نسخه فعلی بر بستر GitHub Pages و ذخیره‌سازی محلی مرورگر اجرا می‌شود. این وضعیت برای نمونه عملیاتی محلی، ورود اطلاعات و آزمون گردش کار مناسب است؛ اما به معنی وجود پایگاه‌داده مرکزی، همگام‌سازی بین کاربران یا همکاری برخط چندکاربره نیست. استقرار این قابلیت‌ها به زیرساخت سرور، احراز هویت، API، سیاست امنیت و عملیات پشتیبان‌گیری مرکزی نیاز دارد.
