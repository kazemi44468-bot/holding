# درگاه هوش مصنوعی محلی مرکز مدیریت دانش

این سرویس، پل اتصال صفحه کتابخانه GitHub Pages به موتورهای هوش مصنوعی نصب‌شده روی **همان رایانه کاربر** است. سرویس فقط روی `127.0.0.1` گوش می‌دهد و فایل صوتی را به سرویس ابری ارسال نمی‌کند.

## قابلیت‌ها
- پیاده‌سازی صوت و ویدئو به متن با faster-whisper و مدل محلی
- پردازش نگارشی، بازنویسی، خلاصه‌سازی، تدوین گزارش، صورت‌جلسه و پرسش‌وپاسخ با Ollama
- دریافت وضعیت سرویس و فهرست مدل‌های زبانی نصب‌شده
- محدودیت حجم ورودی و حذف فایل موقت پس از پردازش

## پیش‌نیازها
1. Python 3.10 یا جدیدتر
2. نصب Ollama و دریافت یک مدل زبانی مناسب فارسی؛ مدل باید پیش از قطع اینترنت روی دستگاه دریافت شده باشد.
3. دریافت یک مدل چندزبانه faster-whisper و نگهداری پوشه آن روی دیسک. مدل را یک‌بار در محیط دارای اینترنت دریافت کنید؛ سرویس با `local_files_only=True` اجرا می‌شود و هنگام اجرا دانلود نمی‌کند.
4. نصب بسته‌های Python با اجرای `start-local-ai.bat`. نصب اولیه به اینترنت نیاز دارد؛ پس از نصب کتابخانه‌ها و مدل‌ها، اجرای سرویس می‌تواند آفلاین باشد.

## پیکربندی ویندوز
در همان پنجره CMD پیش از اجرای سرور:

```bat
set KNOWLEDGE_WHISPER_MODEL=D:\AI-Models\faster-whisper-small
set KNOWLEDGE_WHISPER_DEVICE=cpu
set KNOWLEDGE_WHISPER_COMPUTE=int8
set KNOWLEDGE_OLLAMA_URL=http://127.0.0.1:11434
start-local-ai.bat
```

مسیر مدل باید پوشه کامل مدل محلی باشد، نه نام مدل اینترنتی. برای GPU سازگار می‌توانید `KNOWLEDGE_WHISPER_DEVICE=cuda` و compute type مناسب را تنظیم کنید؛ نصب درایور و CUDA بر عهده محیط میزبان است.

## اتصال در صفحه کتابخانه
- نشانی درگاه: `http://127.0.0.1:8765`
- مدل زبانی: نام دقیق مدلی که در Ollama نصب شده است.
- آزمون اتصال باید وضعیت Ollama و مدل Whisper را نمایش دهد.
- تبدیل صوت به متن از مسیر `/transcribe` و تولید متن از مسیر `/generate` انجام می‌شود.

## ملاحظات امنیت و حریم خصوصی
- سرویس فقط روی loopback یعنی `127.0.0.1` bind می‌شود و از شبکه محلی قابل دسترسی نیست.
- CORS فقط مبدأ GitHub Pages این پروژه و localhost را مجاز می‌کند.
- فایل‌های ارسالی موقت هستند و پس از پردازش حذف می‌شوند؛ متن خروجی فقط وقتی کاربر آن را در کتابخانه ذخیره کند در IndexedDB مرورگر می‌ماند.
- دسترسی به فایل‌ها، مدل‌ها و داده‌های محلی در اختیار کاربر همان رایانه است. از ثبت اطلاعات محرمانه در دستگاه مشترک خودداری کنید.
- این سرویس جایگزین کنترل دسترسی سازمانی، رمزنگاری دیسک یا سیاست نگهداری داده نیست.

## عیب‌یابی
- اگر مرورگر اتصال را مسدود کرد، سرویس را روی همان رایانه اجرا کنید و صفحه را با مرورگر به‌روز باز کنید.
- اگر موتور زبانی دیده نشد، Ollama را اجرا و `ollama list` را بررسی کنید.
- اگر Whisper آماده نبود، مقدار `KNOWLEDGE_WHISPER_MODEL` باید به پوشه مدل موجود اشاره کند.
- برای فایل‌های ویدئویی، نصب FFmpeg روی سیستم ممکن است لازم باشد.
